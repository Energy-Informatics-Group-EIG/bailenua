# Public-figure exclusion list (R27, risk K12, design 5.2 step 6).
#
# "Reject any full-name combination that matches a public-figure list."
#
# PURPOSE AND SCOPE
# This list exists so that no synthetic resident of Baile Nua shares a full name
# with a widely recognisable public figure. It is a NAME-COLLISION filter, not a
# claim about anybody: the only thing a synthetic person could share with a real
# one here is a string.
#
# WHAT IS IN IT
# Names of serving and recent holders of prominent Irish public office, and
# figures whose names are strong enough that the coincidence would be noticed in
# a dataset about an Irish town. Entries are matched case- and accent-insensitively
# (see names.normalise_name), so "Sile Ni Bhriain" and "Síle Ní Bhriain" are the
# same entry.
#
# WHAT IS DELIBERATELY NOT IN IT
# Private individuals. Adding a private person's name here would be the opposite
# of protective: the list is committed to the repository, so it must contain only
# names that are already public.
#
# COVERAGE IS PARTIAL AND IS REPORTED AS SUCH (ISSUES.md I-015)
# No authoritative machine-readable public-figure register for Ireland was found.
# The real protection against resembling a real Cobh resident is therefore NOT
# this list but the three structural measures:
#   * no address in Baile Nua corresponds to a real address;
#   * surnames are drawn uniformly rather than at real frequencies, so the name
#     distribution does not match the real town's (see I-014);
#   * every record carries synthetic = true (D05.synthetic).
# The generator counts and reports how many candidates this list rejected, so its
# contribution is measured rather than assumed.
#
