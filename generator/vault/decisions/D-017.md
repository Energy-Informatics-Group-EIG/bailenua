# D-017 — The checkpoint for day N records the state at the start of day N and is written before the day is run;

## Decision

The checkpoint for day N records the state at the start of day N and is written before the day is run; D16 is written at the 15-minute C1 epoch rather than per minute

## Reason

The checkpoint plus the exchange log are exactly the inputs day N consumes, which is what makes a one-day replay possible; written afterwards it would record end-of-day state and "replaying day N" would in fact run day N+1 from the wrong calendar day. For D16, the thermal time constants are 15 to 140 hours, so a 15-minute sample loses none of the dynamics, and 15 minutes is the epoch the rest of C1 already runs on — the 1-minute step is kept inside the solver and in the device and observation layers, where it matters
