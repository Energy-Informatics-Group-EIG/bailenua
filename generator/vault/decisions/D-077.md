## Decision

The U31 driver and gradient computation move into the repository (validation/heldout_u31.py)

## Reason

The committed heldout_u31.json was produced by a driver that lived only in a scratchpad directory. The statistics were in the repository; the code that called them and wrote the artefact was not, so a committed evidence artefact could not be regenerated from the repository — whatever its contents claimed. Moved with its statistics unchanged (the same paired ttest_rel within groups, the same Welch test for the residual gap, the same gradient definition), and verified by reproducing the baseline exactly: gradient off 1.7682, on 1.6158, old 1.1806, new 0.7307. Re-running U31 must not quietly become a different test
