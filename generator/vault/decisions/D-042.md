# D-042 — The immersion heater is a cylinder device, not an appliance;

| | |
|---|---|
| Date | 2026-10-09 |
| Kind | implementation decision |
| Reversible | Yes |
| Recorded in | `docs/DECISIONS.md table` |

## Decision

The immersion heater is a cylinder device, not an appliance; electric_shower stays an appliance

## Reason

Modelling the immersion on the tank while it was also an appliance with a load signature would have charged every immersion twice, for two different lots of hot water. The electric shower is genuinely an appliance and DEAP says so: it "uses electricity directly rather than from the water heating system", so draw_schedule takes no tank draw for a home that has one. The appliance-failure disruption now reaches the cylinder, which it had to - once the appliance was gone the disruption would otherwise have done nothing
