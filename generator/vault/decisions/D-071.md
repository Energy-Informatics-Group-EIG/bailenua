# D-071 — T6's statistic is incremental cross-validated R², and the null control's confounder is deliberately observed

## Decision

T6's statistic is incremental cross-validated R², and the null control's confounder is deliberately observed

## Reason

In sample, adding any column can only raise R², so an in-sample test would find predictive value in pure noise and the null would pass by construction - a test demonstrates exactly that on the null cohort. And the confounder has to be observed for the null to be fair: with a hidden confounder, stated willingness would legitimately carry information about revealed behaviour and a correct method using it would be marked defective. The null returns -0.0001 against a minimum detectable 0.0039, while the linked arm returns +0.094, so the negative result is informative rather than vacuous
