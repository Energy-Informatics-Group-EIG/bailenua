# D-058 — A D20 label's detectable_from_tier is derived from the sensor channels its text appeals to, not declared alongside it

## Decision

A D20 label's detectable_from_tier is derived from the sensor channels its text appeals to, not declared alongside it

## Reason

The schema defines the field as "the lowest tier at which it is theoretically observable", which is a claim about channels, and TIER_DEVICES says which channels each tier has. So the tier is computed, and the acceptance test re-derives it: a label claiming something its tier cannot see fails, and so does one pitched higher than it needs to be, because "lowest" is part of the contract. The evidence that this is the rule the design meant rather than one invented to pass is that it reproduces all four of design 5.9's hand-written Mary tiers - T1, T2, T1, T3 - which were written before any of this existed
