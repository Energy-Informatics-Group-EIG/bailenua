# D-134 — was_workday is None on the first day of each chained segment.

| | |
|---|---|
| Kind | implementation decision |
| Recorded in | `docs/DECISIONS.md replay section` |

## Decision

run.py looked up yesterday's day type as self.calendar[day.sim_day - 1], an ABSOLUTE index. Two bugs: in a chained segment it indexes past the end of the list, and on sim_day == 0 the guard if day.sim_day > 0 was the only thing preventing calendar[-1] from silently using the last day of the year as the day before 1 January.
