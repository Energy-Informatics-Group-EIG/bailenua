# D-070 — Every G-C mode declares its expected outcome class in advance, and the expected class is often not PASS

## Decision

Every G-C mode declares its expected outcome class in advance, and the expected class is often not PASS

## Reason

Design 5.14 separates a software defect from a recognised limitation, and under the non-identifiable mode a correct estimator *must* fail to recover separate coefficients. Treating that as a bug sends the MIMIC team chasing a property of the design matrix; treating it as a pass hides that the quantity is not recoverable. So a mode coming out PASS where a limitation was declared is itself a finding - an estimator that recovers non-identifiable parameters is recovering its own prior
