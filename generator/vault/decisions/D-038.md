# D-038 — The overnight term is a taper ratio (mean 00:00 over mean 04:00), not a trough hour

| | |
|---|---|
| Date | 2026-10-09 |
| Kind | implementation decision |
| Reversible | Yes |
| Recorded in | `docs/DECISIONS.md table` |

## Decision

The overnight term is a taper ratio (mean 00:00 over mean 04:00), not a trough hour

## Reason

The model's overnight is flat, so its argmin landed on hour 0 against LP1's 04:00 - a four-hour error resting on a 0.02 difference between indistinguishable hours. The argmin of a near-constant function is not a statistic. The ratio says what the argmin only hinted at, and the check fails on it either way, so the band was not chosen to produce a verdict
