## Decision

A plausibility failure the package is known to have is declared once, in KNOWN_PLAUSIBILITY_FAILURES, and both the run hook and the test read it

## Reason

U27's write hook refuses to deliver a package that contradicts a published reference, and after I-044 that meant refusing every run on a defect already written down. Two different events looked identical to it: a defect with an issue number and a defect nobody knew about. The hook now announces a known failure loudly with its issue every run and raises only on an undeclared one. Two rules stop it becoming a waiver - a listed failure that starts PASSING is an error, and every entry must name an issue that exists in ISSUES.md
