# A-40 — the setpoint of a vacant dwelling

| | |
|---|---|
| Verdict | KEPT |
| Assumed | a vacant home is held at 7 C frost protection |
| Retires if | a regulatory or published figure for the heating setpoint of an unoccupied Irish dwelling |

## Verdict note

WP5's ten-year life course produces vacancies, and a vacant house is still connected to the feeder, so the runner needs a setpoint for a dwelling with nobody in it. DEAP has no vacancy case: its demand model assumes an occupied dwelling throughout, so the regulatory anchor is silent rather than contradicted. The assumption is deliberately narrow - at 7 C a vacant Irish home draws almost nothing for most of the year, and the quantity it moves is a standing baseline rather than a peak, so the slice's load factor and peak are nearly insensitive to it.
